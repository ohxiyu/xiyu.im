05

怎么算

两个比值相乘，各自按波动率加权。下面是 的实际数值。

拿币价跟两拨人的成本比，再看市场晃得多厉害。

短期项

P / GMA200

价格 ÷ 200 日几何均价，即 Mayer 倍数。看最近半年多的进场者整体是赚是亏。

长期项

P / RP

价格 ÷ 链上平均成本，即 MVRV。链上成本随网络一起长，不按时间外推。

换算

指数 0.6 / σ

σ 取 365 / 730 天年化波动率。把偏离折算成"波动 60% 的市场里的等价偏离"，对冲波动率收敛。

第一拨人

最近半年多进场的

拿现价跟他们的平均买入价比。

第二拨人

所有拿着比特币的

全网每枚币最后一次挪动时的价格，加起来平均。

市场晃得多厉害

以前一年涨跌几倍很正常，现在稳多了，同样跌 15% 分量更重，要放大来看。

波动越小，放大越多

两拨都赚，偏贵；两拨都亏，便宜；一赚一亏，在 1 附近。它跟"大家真实花出去的钱"比，所以比特币体量再大，这把尺子也不会失效。

Python 实现（pandas）展开 
import numpy as np
# close: 日收盘价；mvrv: Coin Metrics CapMVRVCur（pd.Series）
lp = np.log(close); r = lp.diff()
vol1y = r.rolling(365).std() * np.sqrt(365)
vol2y = r.rolling(730).std() * np.sqrt(365)
cost  = (lp - lp.rolling(200).mean()) / vol1y
value = np.log(mvrv) / vol2y
xiyu999 = np.exp(0.6 * (cost + value))
06

超越黄金进度

不进公式，单独看：比特币离"数字黄金"还有多远。

比特币市值 / 黄金市值4.8%
追平还差21×
追赶速度1.10×/年

追平黄金的路径（logistic、幂律、底部支撑线）都试过，都会随时间漂移，所以只用两个不拟合的数：进度，以及相邻两轮底部占比算出的追赶速度。这一轮底 3.58% 仍高于上一轮 2.61%：叙事未破，但在变慢。

比特币现在的市值约是黄金的 4.8%。每轮熊市的最低点都比上一轮高，说明"数字黄金"这条路还在走；但追得越来越慢，按现在的速度要三十年左右才追平。

07

它会在哪儿出错

用之前先知道它的盲区。

顶部弱

本轮最高 7.6 出现在 2024-03（7.3 万），2025-10 真顶只有 3.6，落在"持有不追"。

底部散

大底 0.38–0.49，急跌（2020-03、2026-02）只到 0.62；0.65 这条线是看着这五次画的。

链上成本变"粘"

ETF 与托管机构的币很少挪动，链上成本的反应可能变慢。

参数在样本内选定

窗口从 270/540 换到 730/730、均线 150/250，大底 0.33–0.66、顶部 5.6–12，结构不变，但不能证明对未来有效。

证伪条件

下一轮大底不落在 0.3–0.65；或比特币/黄金占比跌破 2.61%。

不会逃顶

上一轮它在 7.3 万就喊过热了，真正的顶在 12.6 万。

急跌时只会擦边

像疫情那种几天的暴跌，它只碰到抄底线边上。

大机构的币不怎么动

这会让"全网平均成本"更新变慢。

规则是看着过去定的

过去管用，不等于下次一定管用。
