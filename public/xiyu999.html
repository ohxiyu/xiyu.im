2012 年以来：xiyu999 的顶和底没有漂移

对数坐标。ahr999 的顶部从 95 掉到 1.95，xiyu999 历轮顶部稳定在 6–10，大底在 0.38–0.49。灰虚线为 ahr999，作对照。

老指标 ahr999（灰虚线）越往后越"便宜"，是尺子在变短；xiyu999（黑线）每一轮的高低点差不多在同一个位置，尺子没变。

关键价位

按 的 200 日均价、链上成本和波动率静态反推；这些参数每天在变，价位跟着变。

按今天的情况倒推：价格到哪儿，指数会到哪儿。每天会变一点。

怎么算

沿用 ahr999 的两项相乘，只换掉第二项的锚，并按波动率加权：

xiyu999 = (P / GMA200)^(0.6/σ1y)
        × (P / RP)^(0.6/σ2y)
  • P / GMA200：价格 ÷ 200 日几何均价（Mayer），管短期
  • P / RP：价格 ÷ 链上平均成本（MVRV），替换 ahr999 的幂律估值线，管长期
  • σ1y、σ2y：365 / 730 天年化波动率；0.6/σ 把偏离折算成"波动 60% 市场里的等价偏离"，对冲波动率收敛
  • σ 恰好等于 60% 时，xiyu999 就是"把估值线换成链上成本的 ahr999"

拿币价跟两拨人的成本比：

  • 最近半年多进场的人：现在平均
  • 所有拿着比特币的人：平均成本约 ，现在平均
  • 再看市场晃得多厉害：以前一年涨跌几倍很正常，现在稳多了，同样跌 15% 分量更重，要放大来看

两拨都赚，偏贵；两拨都亏，便宜；一赚一亏，在 1 附近。老指标拿币价跟一条"按日子画好的理想价格线"比，币越大线越离谱；新指标跟"大家真实花出去的钱"比，所以不会因为体量变大而失效。

import numpy as np
# close: 日收盘价；mvrv: Coin Metrics CapMVRVCur（pd.Series）
lp = np.log(close); r = lp.diff()
vol1y = r.rolling(365).std() * np.sqrt(365)
vol2y = r.rolling(730).std() * np.sqrt(365)
cost  = (lp - lp.rolling(200).mean()) / vol1y
value = np.log(mvrv) / vol2y
xiyu999 = np.exp(0.6 * (cost + value))

不进公式，单独看。追平黄金的路径（logistic、幂律、底部支撑线）都试过，全会重演 ahr999 式的漂移，所以只用两个不拟合的数：进度，以及相邻两轮底部占比算出的追赶速度。这一轮底 3.58% 仍高于上一轮 2.61%：叙事未破，但在变慢。

比特币现在的市值约是黄金的 4.8%。每轮熊市的最低点都比上一轮高，说明"数字黄金"这条路还在走；但追得越来越慢，按现在的速度要三十年左右才追平。

它会在哪儿出错

  • 顶部弱：本轮最高 7.6 出现在 2024-03（7.3 万），2025-10 真顶只有 3.6，落在"持有不追"。
  • 底部散：大底 0.38–0.49，急跌（2020-03、2026-02）只到 0.62；0.65 这条线是看着这五次画的。
  • 链上成本变"粘"：ETF 与托管机构的币很少挪动，RP 反应可能变慢。
  • 参数在样本内选定：窗口换成 270/540 到 730/730、均线 150/250，大底 0.33–0.66、顶部 5.6–12，结构不变，但不能证明对未来有效。
  • 证伪条件：下一轮大底不落在 0.3–0.65；或比特币/黄金占比跌破 2.61%。
  • 不会逃顶：上一轮它在 7.3 万就喊过热了，真正的顶在 12.6 万。
  • 急跌时只会擦边：像疫情那种几天的暴跌，它只碰到抄底线边上。
  • 大机构的币不怎么动：这会让"全网平均成本"更新变慢。
  • 规则是看着过去定的：过去管用，不等于下次一定管用。
